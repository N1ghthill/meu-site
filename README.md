## ▶️ Como rodar localmente | Run locally
Abra o `index.html` no navegador ou sirva localmente:
```
python3 -m http.server 8000
```
Acesse `http://localhost:8000`.

---

## 🐍 Script de análise de campanhas | Campaign analyzer
Arquivo: `scripts/analise_campanhas.py`

Instalação das dependências:
```
pip install -r requirements.txt
```

Execução:
```
python3 scripts/analise_campanhas.py
```

Outputs gerados (ignorados pelo Git):
- `dados_campanhas.csv`
- `relatorios/relatorio_YYYYMMDD_HHMMSS.json`
