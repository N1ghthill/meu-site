Terminuz

Aplicação principal • open source (v1.0.1)

Multi-provider • Coding Agent

Agente de código open source para o terminal, com permissões conscientes e múltiplos provedores. Entende repositórios, executa ferramentas e mantém controle de filesystem e shell com o usuário na decisão.

  • TUI interativa (Ink) com streaming, aprovações, diffs e keybindings Vim
  • Modo não-interativo terminuz run para scripts e CI
  • Anthropic, OpenAI, DeepSeek, Groq, Ollama, OpenRouter, OpenCode e MCP
  • Ferramentas de filesystem, shell, git, ripgrep, test, lint e LSP
  • Políticas de caminho, gateway de aprovação, audit log e redação de segredos
Publicado no npm, instalável globalmente. Compatível com a configuração legada do DeepCode.

DevSynapse AI

Projeto principal • open source (v0.8.3)

DeepSeek • Coding Agent

Agente de código local-first para DeepSeek com execução segura de comandos, memória procedural por projeto e visibilidade de custos.

  • Backend FastAPI + frontend React/Vite + SQLite com migrações versionadas
  • Tool calling nativo DeepSeek com streaming, thinking mode e cache
  • Autorização de comandos com escopo por projeto e audit trail
  • Controle de budget diário/mensal com thresholds de alerta
  • Builds desktop com Tauri v2 (Linux .deb/.rpm, Windows, macOS)
+230 testes, 18 releases, CI/CD com GitHub Actions. Templates de workflow inclusos.
